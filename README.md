# michaelbunker.net

Personal portfolio of Michael Bunker — technical writer & content specialist in Illinois.
Live at [michaelbunker.net](https://michaelbunker.net/).

Plain hand-written HTML, CSS, and a little JavaScript. No framework, no build step,
no analytics or tracking. Hosted on GitHub Pages from this repository (default branch);
the domain is registered through Wix, which provides DNS only.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `work.html` | Work — professional writing at Zebra Technologies |
| `projects.html` | Projects — personal builds (local AI workstation, Second Pass, wrist-mounted cyberdeck) |
| `hobbies.html` | Hobbies — PC building, 3D printing, gaming, and more |
| `now.html` | Now — what I'm focused on at the moment |
| `contact.html` | Contact — form via Web3Forms |
| `404.html` | Custom not-found page |

Supporting files: `style.css`, `script.js`, `robots.txt`, `sitemap.xml`,
`.well-known/security.txt`, and `.nojekyll` (the site is static HTML, so Pages
serves the files as-is).

## Editing

Edit the HTML files directly and push to `main`; GitHub Pages publishes automatically.
Keep the shared header, navigation, and footer in sync across pages when they change.
